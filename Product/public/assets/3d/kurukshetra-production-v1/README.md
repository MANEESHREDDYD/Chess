# Kurukshetra Production GLB Pack

This folder contains the first project-authored Blender GLB pack for the
Kurukshetra battlefield.

These files replace the previous procedural fallback at runtime when every slot
is present. They are original generated geometry authored by the MIRROR project
with Blender 5.1 from the user's approved visual direction. They are not copied
from copyrighted reference images, games, films, or third-party model libraries.

Quality note: this is a Blender-generated production pack, not a final
artist-sculpted/scanned AAA asset pack. It is the current runtime 3D model
pack. Photoreal quality requires real sculpted/scanned/Mixamo assets; see
`asset-sources/README.md` and `scripts/ingest-realistic-units.py` for the
pipeline that drops those into these same filenames when available.

Current pack: generated by `scripts/generate-kurukshetra-realistic-glbs.py`.
Each humanoid is a continuous anatomical mesh built with Blender's Skin modifier
(real torso, limbs, fingers, toes, joints, face, hair) carrying synthesized PBR
textures (skin/leather/metal/cloth/wood/hide) exported as WEBP to stay small.
Animals (horse, elephant) and the chariot use the same Skin-modifier anatomy
plus seated/standing riders.

Animation note: every file includes named Blender clips for `idle`, `move`,
`attack`, and `hit`; royal commanders also include `check`. The runtime plays
them with a Three.js `AnimationMixer`; replacements must preserve those clip
names or update the slot contract and verification script together.

Rig note: the standalone humanoid units (`foot-archer`,
`advisor-standard-bearer`, `royal-commander`, both sides) are single skinned
meshes bound to a 19-bone armature, so their clips drive real per-limb motion
(stride, bow draw, recoil, raised sword on check). The mounted/vehicle units
(`horse-archer`, `war-chariot`, `war-elephant-commander`) use whole-object
role-specific clips, but now include visible material-correct geometry for
fingernails, hand wraps, reins, bridles, hooves, stirrups, elephant toenails,
trunk wrinkles, howdah rails, chariot wheel rims, spare javelins, and weapon
hardware. The latest procedural pass also uses a warmer skin/leather palette,
thin ring headbands instead of block helmets, dhoti trouser panels, and crossed
back straps so the rear camera view reads less like dark toy bodies. Because the
rigged humanoid units are `SkinnedMesh` instances, the runtime clones them with
`SkeletonUtils.clone`; a plain `Object3D.clone` would make every instance share
one skeleton.

- `kaurava-war-elephant-commander.glb`

- `kaurava-royal-commander.glb`

Minimum asset requirements:

- Original, commissioned, internally authored, CC0, or repo-compatible licensed.
- No copied copyrighted characters, costumes, model files, or game assets.
- Realistic or stylized-realistic Mahabharata/Kurukshetra direction based on the
  user's references.
- Units must face forward in local +Z before app yaw correction.
- Origin/pivot at ground contact, centered on the chess square.
- Reasonable scale: one unit must fit inside a 1x1 board square footprint.
- PBR materials for skin, leather, fabric, bronze, steel, wood, horse, elephant,
  ivory, dust-worn cloth, and ornamentation.
- Prefer embedded or colocated textures; no external network texture references.
- Rigged/skinned models are preferred for the next fidelity pass.
- Animation clips must include: `idle`, `move`, `attack`, and `hit`; royal
  commanders must also include `check`. Optional role-specific clips such as `horse_leap`, `chariot_roll`,
  `elephant_step`, and `defeat` may be added after the runtime slot contract is
  expanded.

If any file is missing, the app renders the procedural mesh fallback and must not
claim production GLB mode.
