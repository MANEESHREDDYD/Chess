# 3D Reference Lock Brief

Milestone: M-REFERENCE-LOCKED-APPLE-MONO-UI-AND-BOARD-HITTEST-FIX-1
Date: 2026-06-11

## Lock Statement

1. The final 3D style is not approved until user-provided references are reviewed, documented, and approved.
2. The current Kurukshetra 3D battlefield is a reference-guided procedural prototype. It proves board mapping, scene plumbing, fallback behavior, performance guardrails, and first-pass unit silhouettes. It is not final realistic art.
3. Future production battlefield design must be based on user reference images/videos. The user has provided initial visual direction in this chat for archer units, mounted units, elephants, chariots, armor, cloth, and battlefield mood; those images are not stored in the repo unless the user confirms they may be stored.
4. Similarity to the references means visual direction, atmosphere, camera, lighting, material quality, movement style, and battlefield identity. It does not mean copying copyrighted assets, characters, layouts, models, or trade dress.
5. No copyrighted or unlicensed 3D models, textures, rigs, or animations may be used.
6. No UI, README, milestone report, tag, or release note may claim final realistic 3D until approved models/assets/animations exist and screenshots prove the quality bar.

## Allowed Work Before Reference Approval

- Board interaction fixes.

- Text-only reference analysis and asset brief preparation.
- Project-authored procedural geometry/material improvements based on documented references.
- Licensing research.
