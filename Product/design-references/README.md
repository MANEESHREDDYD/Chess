# Design References

This folder is reserved for user-approved visual references for the Kurukshetra battlefield direction.

## Rules

- The user may provide reference screenshots or videos.
- References are for visual direction only.
- Do not copy copyrighted designs, models, characters, compositions, or trade dress directly.
- Do not add real reference images/videos to this repo unless the user explicitly confirms they can be stored here.
- Until storage is confirmed, document reference analysis in text only under `../docs/`.

## Extract From Each Reference

- Camera angle: isometric, tilted board, orbit, fixed strategy camera, FOV, height.
- Lighting: time of day, shadow softness, rim light, haze, contrast.
- Terrain: sand, dust, rocks, trees, boundary, fort/camp backdrop.
- Soldier style: proportions, armor, cloth, hair/headgear, faction readability.
- Horse/elephant/chariot style: armor, caparison, howdah, wheels, yokes, reins.
- Weapon style: bow, arrow, spear, sword, gada/mace, shield, chariot wheels.
- Animation style: marching, riding, leaping, rolling, impact weight, idle motion.
- Capture effect style: dust burst, shield impact, spark flash, fade/dissolve, no blood, no gore.
- UI overlay style: target highlights, legal move hints, check/checkmate emphasis.
- Color palette: terrain base, faction accents, metal, leather, cloth.
- Fidelity target: mobile-game quality, stylized realistic, cinematic, or AAA-like.
