# Design References

This folder holds user-provided reference material for the Kurukshetra Battlefield 3D
direction (and any future visual direction work).

## Rules

- The **user** provides reference screenshots/videos. The agent must not invent or scrape
  references.
- References define **visual direction only** — atmosphere, quality bar, style. We never
  copy copyrighted designs, models, characters, or trade dress directly.
- Do **not** commit reference images/videos to the repo unless the user explicitly
  confirms they may be stored here. Until then, reference analysis is documented in TEXT
  (see `../docs/3d-kurukshetra-reference-expectation.md`).

## What to extract from every reference

| Dimension | Questions to answer |
| --- | --- |
| Camera angle | isometric / tilted board / orbit / fixed strategy camera? height? FOV feel? |
| Lighting | time of day, sun direction, warmth, shadow softness, rim light? |
| Terrain | sand/dust tone, rocks, trees, boundary markers, backdrop (fort walls, camps)? |
| Soldier style | body proportions, armor (leather/bronze), cloth (dhoti, turban/headband), readability |
| Horse/elephant/camel/chariot style | armor/caparison detail, howdah/tower design, wheel/yoke design |
| Weapon style | bow shape, quiver, spear, sword, gada/mace, shield shapes |
| Animation style | weighty vs snappy, march/leap/roll character, idle motion |
| Capture effect style | impact language (dust, sparks, shield hit), duration, non-gory always |
| UI overlay style | how selection/legal/last-move/check read on top of the scene |
| Color palette | base terrain tones vs unit accents (e.g. Pandava blue / Kaurava maroon) |
| Fidelity target | mobile-game / stylized-realistic / cinematic AAA-like |
